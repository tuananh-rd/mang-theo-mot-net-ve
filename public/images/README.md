# Ảnh website

Chỉ đặt ảnh được phép public tại đây. Ghi nguồn, mục đích sử dụng, quyền sử dụng và alt text trong tài liệu asset do Codex quản lý khi có ảnh.

Chưa có ảnh thật được cung cấp. Không sao chép ảnh trẻ từ hồ sơ hoặc nguồn khác vào website mặc định. Không dùng ảnh minh họa như ảnh thực tế tại Mái ấm. File README này không cần xuất lên website.
